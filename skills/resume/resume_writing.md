# Resume Writing — Patterns That Land Interviews

## Bullet formula: Action verb + what + how + quantified impact
- Weak: "Responsible for monitoring servers."
- Strong: "Cut p99 API latency 40% by adding Redis cache-aside and tuning
  connection pools across a 200-node fleet."

Pattern: `<Verb> <result/metric> by <action/technical approach>`.

## Quantify everything possible
Scale (#servers, QPS, data volume, users), % improvement, time saved, $ saved,
incidents reduced, MTTR. Even estimates beat vague claims.

## Strong action verbs
Built, designed, architected, automated, scaled, migrated, reduced, optimised,
debugged, led, shipped, instrumented, hardened. Avoid: helped, assisted,
responsible for, worked on.

## STAR compression for bullets
Situation+Task implied by context; lead with Action, end with Result. One line
each where possible; two max.

## What PE/SRE hiring managers look for
On-call ownership, incident response/MTTR, automation that removed toil, scale
numbers, reliability work (SLOs, error budgets), infra-as-code, debugging depth.

## What Network Engineering hiring managers look for
Protocol depth (BGP/OSPF), datacenter fabric / scale, automation (Ansible,
Python, NETCONF), capacity planning, outage response, vendor/platform breadth.

## Structure (single column, ATS-safe)
1. Name + contact + LinkedIn/GitHub (plain text).
2. Optional 2-line summary tuned to the target role.
3. Skills (grouped, exact tech names).
4. Experience (reverse-chronological, quantified bullets).
5. Projects (if they add signal).
6. Education / certs.

## Tailoring without lying
Reframe real work in the JD's language, reorder to surface relevant items,
strengthen quantification. Never fabricate tools, titles, or tenure.

## Cover letter (when requested)
- Open with a specific hook tied to the role/company — not "I am applying for".
- Map 2–3 of the candidate's strongest, relevant wins to the JD's stated needs.
- Match the JD's tone (fast-paced / collaborative / rigorous).
- Close with a concrete, confident ask. 3–4 short paragraphs.
